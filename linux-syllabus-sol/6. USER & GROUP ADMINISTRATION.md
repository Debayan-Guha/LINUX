# 6.2 Group Management

## 6.2.2 Primary vs secondary groups

In Linux, every user belongs to at least **one primary group** and can belong to **zero or more secondary (supplementary) groups**. Groups are used to manage file permissions and control access to shared resources, allowing administrators to grant permissions to multiple users without configuring each user individually.

**Primary Group**

A **primary group** is the user's default group. It is automatically assigned when the user account is created and is stored in the user's account information (`/etc/passwd`). Whenever the user creates a new file or directory, it is typically assigned this primary group unless special directory permissions (such as the SGID bit) specify otherwise.

Each user can have **only one primary group** at a time.

To view a user's primary group:

```bash
id <username>
```

or

```bash
groups <username>
```

To change a user's primary group:

```bash
sudo usermod -g <group_name> <username>
```


**Secondary (Supplementary) Groups**

A **secondary group** is an additional group that grants the user extra permissions beyond those provided by the primary group. A user can belong to **multiple secondary groups** simultaneously, making it easier to share resources among teams without changing the user's default group.

For example, a developer may have:

- Primary group: `developers`
- Secondary groups: `docker`, `sudo`, `git`

This allows the user to manage Docker containers, execute administrative commands using `sudo`, and collaborate on Git repositories while keeping `developers` as the default group for newly created files.

This means:
- `developers` is the default group for newly created files.
- Membership in `sudo` allows administrative privileges.
- Membership in `docker` allows Docker management.
- Membership in `git` allows access to shared Git resources.

To display all groups a user belongs to:

```bash
groups <username>
```

or

```bash
id <username>
```

To add a user to a secondary group without removing existing group memberships:

```bash
sudo usermod -aG <group_name> <username>
```

> **Important:** Always use the `-a` (append) option together with `-G`. Omitting `-a` replaces all existing secondary groups with the new group.
