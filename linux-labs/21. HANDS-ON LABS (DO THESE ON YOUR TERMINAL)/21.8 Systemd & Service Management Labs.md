## 21.8.3.4 View logs from last 10 minutes: `journalctl --since "10 minutes ago"`
<img width="1365" height="732" alt="image" src="https://github.com/user-attachments/assets/5cc2e6ff-71e2-4399-88d1-0b5d66f43798" />

You can use almost any unit of time by appending "ago". The system recognizes all of these formats out of the box:

*   `"30 seconds ago"`
*   `"5 minutes ago"`
*   `"3 hours ago"`
*   `"2 weeks ago"`
*   `"1 month ago"`
*   `"2 years ago"`
*   `"1 hour 30 minutes ago"`
*   `"2 days 5 hours ago"`

There are many more combinations available depending on the time window you need to target.

## 21.8.3.10 Rotate journal logs: `sudo journalctl --rotate`

`sudo journalctl --rotate` forces the system to close the current journal log file and start a new one — without deleting anything.

<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/083994db-f5cb-44b9-83ff-faaff728b469" />


**Before Rotation**

```text
/var/log/journal/
├── system.journal   (1.2 GB — current active file)
├── system@0001.journal
└── system@0002.journal
```

**After Rotation**

```text
/var/log/journal/
├── system.journal   (0 KB — new active file)
├── system@0001.journal
├── system@0002.journal
└── system@0003.journal   (old file is now archived)
```
